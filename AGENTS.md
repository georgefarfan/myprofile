# AGENTS.md

Project Overview

Este repositorio contiene un portafolio de programador construido con Next.js, React, TypeScript, Tailwind CSS e internacionalización.

La aplicación incluye un perfil personal, experiencia laboral, habilidades, blog, contenido multilingüe, SEO y despliegue en Vercel.

Core Rules

* Preserva la arquitectura existente de Next.js Pages Router.
* Sigue las convenciones y los patrones existentes del proyecto.
* Mantén los cambios enfocados en el alcance solicitado.
* Reutiliza los componentes y las utilidades existentes.
* Evita dependencias y abstracciones innecesarias.
* Mantén un tipado estricto de TypeScript.
* Preserva el comportamiento existente salvo que se pida explícitamente.
* No modifiques archivos no relacionados.
* Nunca ejecutes operaciones destructivas sin aprobación.
